# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/AnkurSingh16/agentic-rag-chatbot/security/advisories/new). Don't open a public issue.

Include the affected component, steps to reproduce and the impact you expect. You'll get an acknowledgement within five working days.

## Scope

In scope: instance or tenant data leaking across boundaries, access-mode bypasses, prompt injection that changes behaviour or discloses data, secrets exposure, and denial of service through cost amplification.

The project is in early development and is not yet deployed anywhere publicly.
