# Tags and search

> Synthetic demo content. Lumen Notes is a fictional product.

## Adding tags

Type `#` followed by a word anywhere in a note, for example `#recipes`. Tags appear in the sidebar under **Tags**. A note can have up to 20 tags.

## Searching

Press `Ctrl+K` (`Cmd+K` on macOS) to open search. Search matches note titles, bodies and tags.

Search operators:

- `tag:recipes` finds notes with the tag `recipes`.
- `notebook:work` limits the search to the Work notebook.
- Put a phrase in double quotes to match it exactly.
