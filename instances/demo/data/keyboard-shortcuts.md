# Keyboard shortcuts

> Synthetic demo content. Lumen Notes is a fictional product.

On macOS, use `Cmd` wherever `Ctrl` is listed.

| Action                | Shortcut       |
| --------------------- | -------------- |
| New note              | `Ctrl+N`       |
| Search                | `Ctrl+K`       |
| Toggle sidebar        | `Ctrl+\`       |
| Bold                  | `Ctrl+B`       |
| Insert checklist      | `Ctrl+Shift+C` |
| Move note to notebook | `Ctrl+Shift+M` |
| Show all shortcuts    | `Ctrl+/`       |
