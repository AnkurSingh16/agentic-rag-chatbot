# Getting started with Lumen Notes

> Synthetic demo content. Lumen Notes is a fictional product.

Lumen Notes is a note-taking app for desktop and mobile. Notes are written in markdown and stored in notebooks.

## Create your first note

1. Open Lumen Notes and choose **New note**, or press `Ctrl+N` (`Cmd+N` on macOS).
2. Type a title on the first line. The title becomes the note's name in the sidebar.
3. Write the body below the title. Changes are saved automatically every two seconds.

## Notebooks

Every note belongs to exactly one notebook. New notes go into the **Inbox** notebook unless you pick another one. To move a note, drag it onto a notebook in the sidebar.
