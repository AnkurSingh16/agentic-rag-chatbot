# Exporting notes

> Synthetic demo content. Lumen Notes is a fictional product.

You can export a single note or a whole notebook.

## Export formats

- **Markdown**: one `.md` file per note, with images in a separate folder.
- **PDF**: one PDF file per note.
- **HTML**: a folder with one page per note and an index page.

## Export a notebook

Right-click the notebook in the sidebar and choose **Export notebook**. Pick a format and a destination folder. Large notebooks can take a few minutes; a progress bar shows how far the export has got.
