# Syncing between devices

> Synthetic demo content. Lumen Notes is a fictional product.

Lumen Notes syncs your notes between devices signed in to the same Lumen account.

## How often notes sync

While a device is online, changes sync within about thirty seconds. A device that was offline syncs as soon as it reconnects.

## Conflicts

If the same note was edited on two devices while one of them was offline, Lumen Notes keeps both versions. The second copy is named with the suffix "(conflict)" so you can merge the changes by hand.

## Turning sync off

Go to **Settings > Sync** and switch off **Sync this device**. Notes already on the device stay there.
